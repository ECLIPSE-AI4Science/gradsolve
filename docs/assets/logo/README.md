# gradsolve logo

The mark is a nabla (∇, "grad") whose three sides are drawn by the Lorenz attractor
(σ = 10, ρ = 28, β = 8/3), the example used throughout the documentation: one long trajectory is integrated
once and its (x, y) projection — the thin figure-eight — is laid along each edge. A solid nabla
stroke carrying the same viridis gradient as the orbits (top → tip) sits on top, with a thin
transparent gap cut around it so the symbol reads on any background.

| File | Use |
|---|---|
| `gradsolve-lockup-light.svg` / `.png` | README header, docs, slides on light backgrounds |
| `gradsolve-lockup-dark.svg` / `.png` | the same on dark backgrounds (GitHub dark mode) |
| `gradsolve-mark-light.svg` / `.png` | the mark alone (1000×1000 viewBox; PNG 1024 px, transparent) |
| `gradsolve-mark-dark.svg` / `.png` | the mark alone, dark-background colours |
| `favicon.svg`, `favicon.ico`, `favicon-{16,32,48,64}.png`, `apple-touch-icon.png` | the gradient stroke alone — the orbits are too fine below ~48 px |

The SVGs embed no fonts: the wordmark is Space Grotesk Medium converted to outlines. The PNGs
are rasterised from the SVGs.

Colours, for anything that has to sit next to the logo: the orbits and stroke are viridis; the
wordmark is `#1a1a1a` on light and `#eef1f4` on dark. The colour used for gradsolve in the figures
is `#0072B2`.
